# Automate Skills Repository

Dieses Repository enthält eine Reihe von Skills für das Automate-Projekt.

## Verwendung

Die Skills können mit folgendem Befehl installiert werden:

```bash
add skill
```

## Verfügbare Skills

- **german-coder**: Ein Skill für das Erstellen von Code in deutscher Sprache
- **github-tooling**: Ein Skill für GitHub-Tooling und Workflows

Weitere Details zu jeder Skill finden Sie in ihren jeweiligen Verzeichnissen.
